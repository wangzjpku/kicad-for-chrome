# 智板工具 - 模型训练与知识库建设要求

**文档版本**: v1.0
**创建日期**: 2026-03-29
**目标**: 解决大模型生成芯片数据和布线不完整的问题

---

## 一、问题分析

### 1.1 当前痛点

| 问题 | 影响 | 根因 |
|------|------|------|
| 大模型缺少芯片数据 | 生成空组件列表 | 训练数据未覆盖所有芯片型号 |
| 布线信息缺失 | 原理图无法连接 | 缺乏引脚定义和连接规则 |
| 封装信息不全 | PCB布局错误 | 未建立芯片-封装-符号映射 |
| 电气参数缺失 | 设计验证失败 | 缺少DC/AC特性数据 |

### 1.2 解决方案架构

```
┌─────────────────────────────────────────────────────────┐
│                    智板工具架构                          │
├─────────────────────────────────────────────────────────┤
│  前端层  │  React + TypeScript + Konva.js               │
├─────────────────────────────────────────────────────────┤
│  API层   │  FastAPI + WebSocket                         │
├─────────────────────────────────────────────────────────┤
│  AI层    │  DeepSeek/自研模型 + RAG知识库增强           │
├─────────────────────────────────────────────────────────┤
│  知识库  │  芯片数据库 + 原理图模板 + 布线规则          │
├─────────────────────────────────────────────────────────┤
│  数据源  │  KiCad库 + 厂商Datasheet + 开源项目         │
└─────────────────────────────────────────────────────────┘
```

## 三、知识库建设方案

### 3.1 知识库分层架构

```
知识库架构
├── L1: 基础层 (Basic)
│   ├── 芯片基础信息 (50,000+)
│   ├── 引脚定义库
│   └── 封装库映射
│
├── L2: 规则层 (Rules)
│   ├── 布线连接规则 (5,000+)
│   ├── 电路设计规范
│   └── DRC规则
│
├── L3: 案例层 (Cases)
│   ├── 典型应用电路 (10,000+)
│   ├── 完整设计方案
│   └── 开源项目参考
│
└── L4: 智能层 (AI)
│   ├── 电路拓扑模式
│   ├── 设计决策树
│   └── 优化建议库
│
└── L5: PCB物理层 (Physical)
    ├── PCB布局案例 (5,000+)
    ├── 层叠结构库
    ├── PCB走线规则
    ├── 制造约束库

    └── 热设计规则
```

### 5.3 实时布线生成方案

要实现"随时给出正确布线结果"，需要：

#### 5.3.1 布线规则引擎

```python
class RoutingEngine:
    def __init__(self):
        self.rules_db = load_routing_rules()
        self.component_db = load_components()

    def generate_routing(self, components: List[Component]) -> Schematic:
        """根据组件列表生成布线"""

        # 1. 识别电路类型
        circuit_type = self.identify_circuit_type(components)

        # 2. 应用最小系统规则
        base_connections = self.apply_minimal_system_rules(components)

        # 3. 应用功能连接规则
        func_connections = self.apply_functional_rules(components, circuit_type)

        # 4. 应用电源布线规则
        power_connections = self.apply_power_rules(components)

        # 5. 优化布线布局
        optimized = self.optimize_layout(
            base_connections + func_connections + power_connections
        )
```

```python
class KiCadImporter:
    def import_symbol_library(self, lib_path: str) -> List[Component]:
```

**kicad-auto-designer 核心算法**:
```python
# 布局流程
1. Component Categorization (组件分类)
   Power Management → Wireless → Processor → Motor Control → Interfaces → Passives

2. Shelf Packing (货架装箱)
   - Next-Fit Decreasing Height (NFDH)
   - Square-aspect-ratio optimization

3. 2D Compaction (二维压缩)
   - 80 iterations of local moves and swaps

4. Force-Directed Relaxation (力导向松弛)
   - 20 iterations with 0.05mm spacing

5. Edge Placement (边缘放置)
   - Antenna → Bottom-left corner
   - Power connectors → Bottom edge
   - Data connectors → Right edge
```
