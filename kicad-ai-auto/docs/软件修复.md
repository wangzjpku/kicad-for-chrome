## 项目概述

**项目目标**: 基于浏览器的 KiCad PCB 设计自动化工具，通过 AI 自然语言描述自动生成原理图和 PCB。

**技术栈**:
- 后端: Python 3.11+ / FastAPI
- 前端: React 18+ / TypeScript / Vite
- 渲染: Konva.js (Canvas)
- KiCad: 9.0+ (IPC API)

## 核心模块说明

### 1. 项目管理 (project_routes.py)

**职责**: 项目 CRUD、原理图/PCB 数据管理

**关键接口**:
- `GET /api/v1/projects` - 获取项目列表
- `POST /api/v1/projects` - 创建项目
- `GET /api/v1/projects/{id}/schematic` - 获取原理图
- `GET /api/v1/projects/{id}/pcb/design` - 获取 PCB

**数据文件**:
- `projects_data.json` - 项目元数据
- `pcb_data.json` - PCB 布局数据
- `schematic_data.json` - 原理图数据

### 2. AI 电路生成 (ai_routes.py)

**职责**: 电路分析、方案生成、原理图/PCB 生成

**关键接口**:
- `POST /api/v1/ai/clarify` - 获取澄清问题
- `POST /api/v1/ai/analyze` - 分析需求生成方案
- `POST /api/v1/ai/chat` - AI 对话

**AI 集成**: Kimi / GLM-4 大模型
**模板系统**: NE555、ESP32、CH340 等

### 3. KiCad IPC 控制 (kicad_ipc_manager.py)

**职责**: KiCad 9.0+ IPC API 控制

**关键接口**:
- `/api/kicad-ipc/start` - 启动 KiCad
- `/api/kicad-ipc/footprint` - 创建封装
- `/api/kicad-ipc/items` - 获取元素列表

### 4. 前端状态管理 (kicadStore.ts)

```typescript
interface KicadStore {
  currentProject: Project | null;
  projects: Project[];
  schematicData: SchematicData | null;
  pcbData: PCBData | null;
  selectedTool: string;
  zoom: number;
  pan: { x: number; y: number };
}
```

## 开发规范

### Python 后端

1. **依赖管理**: 使用 `requirements.txt`
2. **代码风格**: Black + isort
3. **类型提示**: 必须添加类型注解
4. **异常处理**: 使用自定义异常类
5. **日志记录**: 使用 logging 模块

```python
# 示例: 路由函数
from fastapi import APIRouter, HTTPException
from pydantic import BaseModel, Field

router = APIRouter()

class ProjectCreate(BaseModel):
    name: str = Field(..., min_length=1, max_length=100)
    description: str | None = None
```

### TypeScript 前端

1. **依赖管理**: npm
2. **代码风格**: ESLint + Prettier
3. **组件规范**: 函数组件 + Hooks
4. **状态管理**: Zustand

```typescript
// 示例: Store 定义
import { create } from 'zustand';

interface KicadStore {
  currentProject: Project | null;
  setCurrentProject: (project: Project) => void;
}

export const useKicadStore = create<KicadStore>((set) => ({
  currentProject: null,
  setCurrentProject: (project) => set({ currentProject: project }),
}));
```

## 常见问题与修复

### 1. 代码修改不生效

**原因**: Python 进程缓存旧代码

**解决方案**:
```bash
taskkill //F //IM python.exe
cd agent && ./venv/Scripts/python.exe main.py
```

### 2. 原理图数据不持久化

**检查点**:
- 创建项目时是否调用 `_save_schematic_data()`
- 文件权限是否正确

### 3. 前端构建失败

**解决方案**:
```bash
cd web
npm run build
# 检查是否有编译错误
```

### 4. API 返回 500 错误

**排查步骤**:
1. 检查后端控制台错误日志
2. 验证数据文件完整性
3. 确认端口 8000 无冲突进程
