## 自动布线API详情

### 请求参数

#### AutoRouteRequest
```json
{
  "net_class": "default",    // 网络类名称
  "ripup_days": false,       // 是否允许拆线重布
  "stability": 50,           // 稳定性参数 (0-100)
  "max_iterations": 100     // 最大迭代次数
}
```

#### RoutingRule
```json
{
  "name": "string",
  "description": "string",
  "min_trace_width": 0.2,   // 最小走线宽度 (mm)
  "max_trace_width": 2.0,   // 最大走线宽度 (mm)
  "default_trace_width": 0.25,
  "min_clearance": 0.2,     // 最小间距 (mm)
  "via_diameter": 0.8,      // 过孔直径 (mm)
  "via_drill": 0.4,        // 过孔钻孔 (mm)
  "impedance_controlled": false
}
```

## 使用方法

### 1. 启动KiCad并连接
```bash
# 方法1: 通过API启动
curl -X POST http://localhost:8000/api/kicad-ipc/start

# 方法2: 手动启动KiCad并启用IPC服务
# Tools → External Plugin → Start Server
```

### 2. 设置布线规则
```bash
curl -X POST http://localhost:8000/api/kicad-ipc/routing-rules \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Standard",
    "description": "Standard PCB routing",
    "min_trace_width": 0.2,
    "max_trace_width": 1.0,
    "default_trace_width": 0.25,
    "min_clearance": 0.2,
    "via_diameter": 0.6,
    "via_drill": 0.3,
    "impedance_controlled": false
  }'
```

### 3. 执行自动布线
```bash
curl -X POST http://localhost:8000/api/kicad-ipc/auto-route \
  -H "Content-Type: application/json" \
  -d '{
    "net_class": "default",
    "ripup_days": false,
    "stability": 50,
    "max_iterations": 100
  }'
```

### 4. 其他操作
```bash
# 获取鼠线信息
curl http://localhost:8000/api/kicad-ipc/ratsnest

# 显示/隐藏鼠线
curl -X POST "http://localhost:8000/api/kicad-ipc/show-ratsnest?show=true"

# 清除所有走线
curl -X POST http://localhost:8000/api/kicad-ipc/clear-tracks

# 获取当前布线规则
curl http://localhost:8000/api/kicad-ipc/routing-rules
```
