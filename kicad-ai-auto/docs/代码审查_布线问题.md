# 代码审查报告 - 布线相关问题

**审查范围**: kicad-ai-auto 项目

## 发现的问题

### 问题1: 自动布线API未真正实现 (严重)

**文件**: `agent/kicad_ipc_manager.py` 第815-841行

**问题描述**:
自动布线函数 `auto_route()` 没有真正执行自动布线，只是返回"Routing attempted"消息：

```python
def auto_route(self, ...):
    try:
        # 尝试通过Action调用自动布线
        try:
            result = self.client.run_action(
                "pcbnew.Router",
                {"net_class": net_class, "ripup_days": ripup_days},
            )
            return {"success": True, "method": "action", "result": result}
        except Exception as e:
            logger.warning(f"Action-based routing failed: {e}")

        # 简化实现 - 实际上什么都没做！
        return {"success": True, "method": "manual", "message": "Routing attempted"}
```

**影响**:
- 调用自动布线API时只返回成功消息，但没有实际执行布线
- 用户无法通过API执行真正的自动布线

---

### 问题2: 前端缺少自动布线调用 (中等)

**文件**: `web/src/`

**问题描述**:
前端没有调用后端的自动布线API (`/api/kicad-ipc/auto-route`)。

当前只有手动布线工具 `RoutingTool.tsx`，用户需要手动绘制每条走线。

**建议**:
在工具栏或右键菜单中添加"自动布线"按钮，调用后端API。

---

### 问题3: PCB生成时走线算法简单 (中等)

**文件**: `agent/routes/project_routes.py` 第84-177行

**问题描述**:
自动生成的走线算法过于简单：

1. 只对VCC/GND网络自动生成走线
2. 走线只是简单的L型直角连接
3. 没有考虑最短路径或最优路径
4. 没有使用KiCad的FreeRouting引擎

```python
# 只有VCC/GND网络生成走线
if net_name in ["VCC", "GND", "V3"]:
    # 简单的L型连接
    track = {
        "points": [
            {"x": pads_on_net[i]["x"], "y": pads_on_net[i]["y"]},
            {"x": pads_on_net[i+1]["x"], "y": pads_on_net[i]["y"]},
            {"x": pads_on_net[i+1]["x"], "y": pads_on_net[i+1]["y"]}
        ]
    }
```

### 问题4: 多层板过孔设置缺失 (轻微)

**问题描述**:
生成走线时只设置了单层(F.Cu)，没有考虑过孔和多层板设置。

```python
track = {
    "layer": "F.Cu",  # 永远是顶层

```

## 修复建议

### 修复1: 实现真正的自动布线

在 `kicad_ipc_manager.py` 中实现真正的自动布线：

```python
def auto_route(self, net_class="default", ...):
    """执行真正的自动布线"""
    try:
        # 方法1: 通过菜单调用FreeRouting
        self.board.ExecuteRemoteCommand("RunFreeRouter")

        # 方法2: 使用Python API
        import pcbnew
        router = pcbnew.FREEROUTE_IFACE()
        router.DoRouting()

        return {"success": True, "message": "Auto-routing completed"}
    except Exception as e:
        return {"success": False, "error": str(e)}
```
