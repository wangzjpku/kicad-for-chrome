## 修复的问题

### 问题1: KiCadIPCManager _connected属性未初始化 (严重) ✅ 已修复

**文件**: `agent/kicad_ipc_manager.py` 第66-94行

**根本原因**:
`__init__` 方法中有一个错误的 return 语句（第88行），导致后续的属性初始化代码没有执行：

```python
def __init__(self, config: Optional[KiCadConnectionConfig] = None):
    self._is_docker = ...
    return self._is_docker  # 错误！导致后面代码不执行
    self.config = config or KiCadConnectionConfig()  # 永远不会执行
    self._connected = False  # 永远不会执行
```

**修复方案**:
将属性初始化代码移到 return 语句之前：

```python
def __init__(self, config: Optional[KiCadConnectionConfig] = None):
    self._is_docker = ...
    # 初始化所有属性
    self.config = config or KiCadConnectionConfig()
    self.client = None
    self.board = None
    self._connected = False
```

**修复后结果**:
- API 调用不再崩溃
- 返回正确的错误信息 "KiCad not connected"（当 KiCad 未连接时）
