## 三、自动布线实现原理

代码通过KiCad IPC API调用 `pcbnew.Router` action:

```python
def auto_route(self, net_class="default", ripup_days=False, stability=50, max_iterations=100):
    # 尝试调用KiCad内置的自动布线功能
    result = self.client.run_action(
        "pcbnew.Router",
        {"net_class": net_class, "ripup_days": ripup_days}
    )
```

## 四、当前限制

### 需要手动操作

**KiCad IPC服务需要在GUI中手动启用**:
1. 打开KiCad
2. 进入PCB编辑器
3. 菜单: Tools → External Plugin → Start Server
4. 启用后，IPC连接会一直保持直到KiCad关闭

### 连接成功后可用的功能

1. **自动布线**: 完整支持KiCad FreeRouting引擎
2. **规则设置**: 可配置走线宽度、间距、过孔等
3. **鼠线操作**: 显示/隐藏未连接的网络
4. **走线清除**: 一键清除所有走线重新布线

## 五、使用步骤

### 步骤1: 启动KiCad并启用IPC服务
```
1. 打开KiCad 9.0
2. 打开任意PCB文件（或新建）
3. 点击菜单: Tools → External Plugin → Start Server
4. 确认服务已启动（状态栏会显示）
```

### 步骤2: 通过API连接
```bash
# 方法1: 通过API启动（如果KiCad未运行）
curl -X POST http://localhost:8000/api/kicad-ipc/start

# 方法2: 刷新前端页面，自动检测连接
```

### 步骤3: 执行自动布线
```bash
# 设置布线规则（可选）
curl -X POST http://localhost:8000/api/kicad-ipc/routing-rules \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Standard",
    "description": "Standard PCB",
    "min_trace_width": 0.2,
    "default_trace_width": 0.25,
    "min_clearance": 0.2,
    "via_diameter": 0.6,
    "via_drill": 0.3
  }'

# 执行自动布线
curl -X POST http://localhost:8000/api/kicad-ipc/auto-route \
  -H "Content-Type: application/json" \
  -d '{
    "net_class": "default",
    "stability": 50,
    "max_iterations": 100
  }'
```
