## 布线验证方法

### 方法1: 通过网表验证
原理图布线生成后，可以通过网表导出验证连接正确性：

```python
# 原理图数据
schematic_data = {
    "components": [...],
    "nets": [
        {"name": "VCC", "connections": [{"ref": "U1", "pin": "VDD"}, ...]}
    ]
}

# 导出JSON网表
json_netlist = exporter.export_json(schematic_data)

# 验证网络
netlist_data = json.loads(json_netlist)
for net in netlist_data["nets"]:
    print(f"网络: {net['name']}")
    for node in net['nodes']:
        print(f"  - {node['ref']}.{node['pin']}")
```

## 技术细节

### 布线实现原理

`SchematicGeneratorV2` 类的布线功能：

1. **自动布线**: 使用 `kicad-sch-api` 的 `add_wire_between_pins()` 方法
   - 自动找到引脚位置
   - 计算正交路由(Manhattan routing)

2. **连接格式**: 支持 "元件.引脚" 格式
   - 例如: "U1.1" 表示 U1 的第1引脚
   - "R2.2" 表示 R2 的第2引脚

3. **回退机制**: 如果自动布线失败，使用手动线段添加

### 代码位置
- 生成器: `agent/generators/schematic_v2.py`
- 布线方法: `_add_wires()` (第174-210行)
