2. **点击"🤖 AI 创建"按钮** - 无法执行点击
3. **点击用户下拉菜单** - 无法执行点击
4. **点击Open按钮打开项目** - 无法执行点击
5. **点击Delete按钮删除项目** - 无法执行点击
6. **输入项目名称** - 无法执行输入

- `browser_type` 工具报错: `Invalid input: expected string, received undefined`
