用户再次报告 Stage 8（PCB 和 Schematic 编辑器）显示空白画布。经过详细调查，发现虽然数据加载正常，但内容无法渲染到 canvas。

### 根本原因分析

1. **Stage/Layer 架构错误**
   - 原本将 x/y 平移属性设置在 Stage 上
   - 导致整个画布被移出可视区域

2. **Layer 渲染问题**
   - 内容 Layer 有 13 个子元素但无法渲染
   - 即使调用 `draw()` 方法，canvas 仍为空白

3. **缺少拖拽功能**

### 已实施的修复

#### 1. Stage/Layer 架构修正 (SchematicEditor.tsx & PCBEditor.tsx)

**修改前:**
```tsx
<Stage x={pan.x} y={pan.y}>
  <Layer>
```

**修改后:**
```tsx
<Stage>  // Stage 固定在原点
  <Layer x={pan.x} y={pan.y}>  // Layer 应用平移变换
```

**原因:** Konva 中 Stage 应该保持位置不变，Layer 负责内容变换

#### 2. 添加拖拽平移功能

```typescript
const [isDragging, setIsDragging] = useState(false);
const [dragStart, setDragStart] = useState({ x: 0, y: 0 });

const handleMouseDown = (e) => {
  if (e.target === e.target.getStage()) {
    setIsDragging(true);
    setDragStart({
      x: e.evt.clientX - pan.x,
      y: e.evt.clientY - pan.y
    });
  }
};

const handleMouseMove = (e) => {
  if (isDragging) {
    setPan({
      x: e.evt.clientX - dragStart.x,
      y: e.evt.clientY - dragStart.y
    });
  }
};

const handleMouseUp = () => setIsDragging(false);
```

#### 3. 添加强制重绘机制

```typescript
useEffect(() => {

      setTimeout(() => {

        console.log('[SchematicEditor] Forced Stage redraw (t=100)');
      }, 100),
      setTimeout(() => {
        if (contentLayerRef.current) {

        contentLayerRef.current?.draw();

      }, 1000),
    ];
    return () => timers.forEach(clearTimeout);
  }
}, [schematicData, width, height]);
```
