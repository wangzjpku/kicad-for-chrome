## 第二阶段：根本原因

### 发现问题

通过后端日志发现保存原理图文件时出错：
```
ERROR - [ProjectRoutes] Failed to save schematic: Invalid format specifier '.3f - 2' for object of type 'float'
```

**错误代码** (project_routes.py:271):
```python
# 错误写法
lines.append(f'    (property "Reference" "{ref}" (at {pos_x:.3f - 2} {pos_y:.3f - 2} 0)')
```

**问题分析**：
- Python f-string 格式化优先级问题
- `{pos_x:.3f - 2}` 被解释为格式化后再减2
- 正确写法应该是先减后格式化

---

## 第三阶段：修复

### 修复代码

**文件**: `kicad-ai-auto/agent/routes/project_routes.py`

**修改**:
```python
# 修改前（错误）
lines.append(f'    (property "Reference" "{ref}" (at {pos_x:.3f - 2} {pos_y:.3f - 2} 0)')

# 修改后（正确）
lines.append(f'    (property "Reference" "{ref}" (at {pos_x - 2:.3f} {pos_y - 2:.3f} 0)')
```

### 同时修复的问题

在 `project_routes.py` 中还有一个相关问题：
- 项目创建时过早设置了 `schematicFile` 路径
- 即使保存失败也会返回路径
- 修复后只在文件保存成功后才设置路径
