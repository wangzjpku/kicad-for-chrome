# Ralph Loop 迭代测试提示词

## 使用方法
将以下提示词完整复制粘贴到 Claude Code 中执行

---

## 完整提示词 (复制以下内容)

```
请执行 Ralph Loop 迭代测试流程，目标是验证并修复 AI 生成的原理图和 PCB 设计问题。

## 任务目标
1. 阅读测试手册: kicad-ai-auto/docs/quality-assurance/AI-QA-MANUAL.md
2. 运行测试并生成问题报告: 问题.md
3. 修复所有发现的问题
4. 迭代至少 20 次直到问题.md 中的问题 100% 解决

## Ralph Loop 配置
- 最大迭代次数: 20
- 收敛条件: 0 个 ERROR 级别问题
- 每次迭代必须: 测试 → 记录问题 → 修复 → 重新测试

## 测试范围
按优先级执行以下测试:

### P0 必须通过 (阻塞发布)
- [ ] 网表一致性: 原理图与PCB网络100%一致
- [ ] 连接完整性: 所有连线到达正确端点
- [ ] 封装匹配: 所有元件符号-封装对应正确

### P1 重要测试
- [ ] DRC检查: 0 错误
- [ ] ERC检查: 0 错误
- [ ] 电源网络: VCC/GND 正确连接

### P2 建议测试
- [ ] 布局合理性: 元件间距>=0.5mm
- [ ] 走线质量: 无锐角走线
- [ ] 视觉验证: 无明显问题

## 迭代流程

### 第1次迭代
1. 读取测试手册了解测试方法
2. 执行所有P0测试
3. 生成 问题.md 文件，格式如下:

```markdown
# 问题清单 - 迭代1

**日期**: YYYY-MM-DD
**状态**: 待修复

## ERROR 级别问题 (必须修复)

| 编号 | 类别 | 问题描述 | 文件 | 状态 |
|------|------|----------|------|------|
| E001 | 网表 | xxx | xxx.py | 待修复 |

## WARNING 级别问题 (建议修复)

| 编号 | 类别 | 问题描述 | 文件 | 状态 |
|------|------|----------|------|------|
| W001 | 布局 | xxx | xxx.ts | 待修复 |

## 统计
- ERROR: X 个
- WARNING: Y 个
- 通过率: Z%
```

4. 修复所有 ERROR 级别问题
5. 更新 问题.md 状态

### 第2-20次迭代
重复以下步骤直到收敛:
1. 重新运行所有测试
2. 更新 问题.md (添加新迭代结果)
3. 修复新发现的问题
4. 验证修复效果
5. 如果没有 ERROR 问题，标记为收敛

## 收敛判断
- 收敛: 0 个 ERROR，WARNING <= 3 个
- 部分收敛: ERROR 逐次减少
- 未收敛: ERROR 数量不变或增加

## 最终输出
完成迭代后生成:
1. 问题.md - 完整问题追踪
2. 最终报告.md - 测试结果汇总
3. 修复记录.json - 所有修复操作的机器可读记录

## 开始执行
请立即开始第一次迭代，读取测试手册并执行测试。
```
