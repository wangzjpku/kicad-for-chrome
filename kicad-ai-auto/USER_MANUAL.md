## 1. 系统简介

### 1.1 什么是 KiCad for Chrome？

KiCad for Chrome 是一个基于浏览器的 KiCad 辅助设计控制系统。它允许用户通过 Web 界面控制 KiCad EDA 软件，并提供 AI 辅助设计功能，帮助用户快速创建电路项目。

### 1.2 核心特色：AI 自动设计

本系统最大的特色是 **AI 自动设计功能**，它可以：

1. **智能需求分析**：自动理解用户的电路需求描述
2. **自动选型**：根据需求推荐合适的电子元件和芯片
3. **原理图生成**：自动生成完整的电路原理图
4. **PCB 布局建议**：提供元件摆放和走线建议
5. **参数计算**：自动计算电路参数（电压、电流、电阻值等）

### 1.3 主要功能

| 功能模块 | 说明 |
|---------|------|
| 项目管理 | 创建、打开、保存、删除 PCB 项目 |
| PCB 编辑器 | 放置元件、走线、过孔、铺铜等 |
| 原理图编辑器 | 绘制电路原理图、元件连线 |
| AI 助手 | 通过自然语言描述需求，AI 自动生成项目方案 |
| 导出功能 | 导出 Gerber、BOM、坐标文件等 |
| DRC 检查 | 设计规则检查 |

## 2. 快速开始

### 2.1 启动服务

#### 步骤 1：启动后端服务

```bash
# 进入 agent 目录
cd kicad-ai-auto/agent

# 激活虚拟环境并启动
./venv/Scripts/python.exe main.py
```

**验证方法**：打开浏览器访问 http://localhost:8000/docs ，应该看到 API 文档页面。

```bash
# 进入 web 目录
cd kicad-ai-auto/web
```

## 3. 项目管理

### 3.1 创建新项目

#### 方法一：手动创建

**操作步骤**：

1. 在项目列表页面，点击 **"+ 新建项目"** 按钮
2. 在弹出的对话框中输入项目名称
3. （可选）输入项目描述
4. 点击 **"创建"** 按钮

**测试案例 3.1.1：创建空白项目**

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 点击 "+ 新建项目" | 弹出创建对话框 |
| 2 | 输入名称 "MyFirstPCB" | 名称显示在输入框 |
| 3 | 点击 "创建" | 对话框关闭，项目出现在列表中 |
| 4 | 刷新页面 | 项目仍然存在 |

#### 方法二：AI 智能创建

**操作步骤**：

1. 在项目列表页面，点击 **"AI 智能创建"** 按钮
2. 在弹出的对话框中描述你的电路需求
3. 点击 **"生成方案"**
4. AI 会分析需求并生成元件清单和参数
5. 确认方案后点击 **"创建项目"**

**测试案例 3.1.2：AI 创建稳压电源项目**

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 点击 "AI 智能创建" | 弹出 AI 对话框 |
| 2 | 输入 "帮我做一个5V稳压电源" | 文本显示在输入框 |
| 3 | 点击 "生成方案" | 显示元件清单（LM7805、电容等） |
| 4 | 点击 "创建项目" | 项目创建成功并打开 |

### 3.2 打开项目

**操作步骤**：

1. 在项目列表中找到要打开的项目
2. 点击项目卡片或双击项目名称
3. 系统会打开项目编辑界面

**测试案例 3.2.1：打开已有项目**

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 在列表中找到 "test" 项目 | 看到项目卡片 |
| 2 | 点击项目卡片 | 进入 PCB 编辑器界面 |
| 3 | 点击顶部导航的 "项目" | 返回项目列表 |

### 3.3 删除项目

**操作步骤**：

1. 在项目列表中，将鼠标悬停在项目卡片上
2. 点击出现的 **"删除"** 图标（🗑️）
3. 在确认对话框中点击 **"确认删除"**

**测试案例 3.3.1：删除项目**

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 鼠标悬停在 "test" 项目上 | 显示操作按钮 |
| 2 | 点击删除图标 | 弹出确认对话框 |
| 3 | 点击确认删除 | 项目从列表中消失 |
| 4 | 刷新页面 | 确认项目已删除 |

### 4.2 PCB 设计基础概念

#### 4.2.1 什么是 PCB？

PCB (Printed Circuit Board) 即印刷电路板，是电子元件的支撑体和电气连接的载体。

**PCB 的基本结构**：

```
┌────────────────────────────────────────────────┐
│  丝印层 (Silkscreen) - 白色                   │
│  印有元件编号、 logo、 文字                    │
├────────────────────────────────────────────────┤
│  阻焊层 (Solder Mask) - 绿色/红色/蓝色        │
│  保护铜箔， 防止短路                           │
├────────────────────────────────────────────────┤
│  铜层 (Copper) - 金属走线                      │
│  电流通过的路径                                │
├────────────────────────────────────────────────┤
│  基材 (Substrate) - FR4 玻璃纤维              │
│  绝缘支撑层                                    │
├────────────────────────────────────────────────┤
│  铜层 (Copper) - 底层金属走线                  │
├────────────────────────────────────────────────┤
│  阻焊层 (Solder Mask) - 底层                   │
├────────────────────────────────────────────────┤
│  丝印层 (Silkscreen) - 底层文字                 │
└────────────────────────────────────────────────┘
```

#### 4.2.2 常用层说明

| 层名 | 用途 | 颜色(典型) |
|------|------|------------|
| F.Cu | 顶层铜 | 红色 |
| B.Cu | 底层铜 | 蓝色 |
| F.Silkscreen | 顶层丝印 | 白色 |
| B.Silkscreen | 底层丝印 | 白色 |
| F.Mask | 顶层阻焊 | 绿色半透明 |
| B.Mask | 底层阻焊 | 绿色半透明 |
| Edge.Cuts | 板边外形 | 黄色 |

#### 4.2.3 常见封装尺寸

**电阻/电容 (SMD)**

| 封装 | 尺寸 (mm) | 功率/电压 |
|------|-----------|-----------|
| 0201 | 0.6×0.3 | 0.05W/16V |
| 0402 | 1.0×0.5 | 0.062W/25V |
| 0603 | 1.6×0.8 | 0.1W/50V |
| 0805 | 2.0×1.25 | 0.125W/150V |
| 1206 | 3.2×1.6 | 0.25W/200V |

**IC 封装**

| 封装 | 引脚数 | 描述 |
|------|--------|------|
| SOIC-8 | 8 | 小型贴片IC |
| TSSOP-20 | 20 | 薄小封装 |
| QFN-32 | 32 | 无引脚方形 |
| LQFP-48 | 48 | 薄型方脚 |
| BGA-144 | 144 | 球栅阵列 |

### 4.3 常用工具详解

#### 4.3.1 选择工具 (Select Tool)

**功能**：选择、移动、对齐元件

**界面图标**：箭头光标

**操作方法**：

1. **选中单个元件**
   - 点击元件 → 元件周围显示绿色虚线边框
   - 显示属性面板

2. **框选多个元件**
   - 按住鼠标左键拖动
   - 出现绿色矩形框
   - 框内的元件被选中

3. **移动元件**
   - 选中元件后拖动
   - 释放鼠标放置
   - 保持按住 Shift 可复制

4. **删除元件**
   - 选中元件
   - 按 Delete 或 Backspace 键
   - 或右键 → 删除

**快捷键**：`S` - 切换到选择工具

#### 4.3.2 走线工具 (Route Tool)

**功能**：绘制铜膜走线，连接元件

**界面图标**：曲折线

**操作方法**：

1. 点击走线工具或按 `X` 键
2. 光标变为十字形
3. 在起点（焊盘或过孔）上点击开始
4. 移动鼠标到下一个点
   - 点击添加转角
   - 移动时显示预览线
5. 重复直到终点
6. 双击结束走线
7. 按 ESC 取消

**走线设置**：
- 线宽：在属性面板设置
- 层：在底部状态栏切换
- 角度：按 `X` 切换角度模式

**角度模式**：
- 45° (推荐)
- 90° 
- 任意角度

**走线宽度参考**：

| 电流 | 最小线宽 (1oz铜) |
|------|-----------------|
| 0.5A | 0.3mm |
| 1A | 0.6mm |
| 2A | 1.2mm |
| 5A | 3.0mm |

**测试案例 4.3.2.1：绘制简单走线**

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 点击走线工具 | 光标变为十字 |
| 2 | 在焊盘上点击 | 显示走线起点圆点 |
| 3 | 移动鼠标 | 显示动态走线预览 |
| 4 | 在目标位置点击 | 添加第一个转角 |
| 5 | 双击结束 | 走线完成，显示实线 |
| 6 | 按 ESC | 退出走线模式 |

#### 4.3.3 过孔工具 (Via Tool)

**功能**：在不同电路板层之间建立连接

**界面图标**：圆环带孔

**操作方法**：

1. 点击过孔工具或按 `V` 键
2. 在走线需要换层的位置点击
3. 系统自动创建过孔
4. 继续在另一层走线

**过孔规格**：

| 类型 | 直径 | 钻孔 | 应用 |
|------|------|------|------|
| 微型 | 0.3mm | 0.15mm | 高密度 |
| 标准 | 0.6mm | 0.3mm | 普通 |
| 电源 | 0.8mm | 0.4mm | 大电流 |

#### 4.3.4 元件放置工具 (Footprint Tool)

**功能**：放置元件封装

**界面图标**：IC 芯片形状

**操作方法**：

1. 点击元件工具
2. 打开元件库搜索面板
3. 输入封装名称搜索
4. 选择需要的封装
5. 封装附着在光标上
6. 在目标位置点击放置
7. 按 ESC 取消

**常用封装库**：

| 库名 | 内容 |
|------|------|
| Resistor_SMD | 贴片电阻 |
| Capacitor_SMD | 贴片电容 |
| Inductor_SMD | 贴片电感 |
| LED_SMD | 贴片LED |
| Diode_SMD | 贴片二极管 |
| Package_SO | SOIC, TSSOP |
| Package_QFP | QFP, LQFP |
| Package_BGA | BGA 封装 |
| Connector_USB | USB 接口 |
| Connector_PinHeader | 排针 |

#### 4.3.5 铺铜工具 (Zone Tool)

**功能**：创建大面积铜区域，用于接地或电源

**界面图标**：填充区域

**操作方法**：

1. 点击铺铜工具或按 `P` 键
2. 在 PCB 边缘内部点击开始绘制边界
3. 依次点击定义多边形边界
4. 右键结束边界绘制
5. 弹出铺铜设置对话框
6. 选择网络（ GND, VCC 等）
7. 点击确认完成铺铜

**铺铜设置**：

| 参数 | 说明 | 推荐值 |
|------|------|--------|
| 网络 | 连接的网络 | GND |
| 层 | 铺铜层 | F.Cu / B.Cu |
| 间距 | 与走线间距 | 0.2mm |
| 最小宽度 | 铜区域最小宽度 | 0.2mm |
| 填充模式 | 实铜/网格 | 实铜 |

### 4.4 层管理详解

#### 4.4.1 切换工作层

**方法1：底部状态栏点击**
- 点击状态栏中的层名
- 弹出层选择菜单
- 选择目标层

**方法2：快捷键**
- `PgUp`：向内层切换
- `PgDn`：向外层切换

**方法3：右键菜单**
- 右键点击画布空白处
- 选择 "层" → 目标层

#### 4.4.2 常用层切换

| 从 | 到 | 快捷键 |

#### 4.6.2 布局原则

**功能分区**：

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│  ┌─────────┐   ┌─────────────┐   ┌─────────────┐   │
│  │ 电源输入 │   │   主控区域   │   │   接口区域   │   │

└─────────────────────────────────────────────────────────┘
```

**布局要点**：
- 电源输入放边缘
- 主控芯片放中央
- 退耦电容靠近芯片电源引脚
- 高速信号线短
- 模拟/数字分离

#### 4.6.3 走线规则

**线宽计算**：
- 电源线：按电流计算 (1A ≈ 0.5mm)
- 信号线：0.2-0.3mm
- 地线：尽量宽

**走线间距**：
- 最小间距：0.2mm (常规)
- 高压间距：≥ 0.5mm
- 射频间距：≥ 2W

**走线角度**：
- 推荐 45° 转角
- 避免 90° 转角
- 避免锐角

### 5.2 原理图基础概念

#### 5.2.1 什么是原理图？

原理图是用符号表示电路中各元件及其连接关系的图形。它不关心元件的实际物理外形，只关注电气连接。

**原理图的组成**：

```
┌─────────────────────────────────────────────────────────────┐
│                      原理图示例                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│         VCC                                                  │
│          │                                                   │
│     ┌────┴────┐                                            │
│     │         │                                            │
│    ┌┴┐       ┌┴┐                                          │
│    │R1│       │R2│   ← 电阻符号 (Device:R)              │
│    └─┬┘       └─┬┘                                          │
│      │         │                                            │
│      └────┬────┘                                            │
│           │                                                 │
│          ┌┴┐                                                │
│          │U1│          ← IC符号 (MCU:STM32)               │
│          │  │                                                │
│          └─┬┘                                                │
│           │                                                  │
│          GND                                                 │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

#### 5.2.2 原理图符号说明

| 符号 | 名称 | 说明 |
|------|------|------|
| ~~∿~~ | 电阻 | 限制电流 |
| ~~-||-$ | 电容 | 存储电荷 |
| ~~━━━━━~~ | 电感 | 储能 |
| ▶\| | 二极管 | 单向导电 |
| ▶━▶ | 三极管 | 放大/开关 |
| ▭ | IC | 集成电路 |
| ┴或⊥ | GND | 接地 |
| ┏VCC | VCC | 电源正 |

#### 5.2.3 原理图绘制规则

1. **信号流向**：通常从左到右、从上到下
2. **电源位置**：VCC 在上方，GND 在下方
3. **导线交叉**：
   - 有圆点 = 电气连接
   - 无圆点 = 跨过不连接
4. **网络名**：相同网络名的导线在电气上相连

### 6.3 AI 原理图自动生成详解

#### 6.3.1 原理图生成流程

AI 生成原理图的具体流程：

```
1. 分析需求 → 2. 确定架构 → 3. 选择元件 → 4. 计算参数 → 5. 生成原理图

```

#### 6.3.2 AI 生成的原理图包含内容

AI 生成的原理图包含以下完整信息：

**1. 元件符号 (Symbols)**
- 每个元件的原理图符号
- 元件位号 (Reference): R1, C1, U1, U2...
- 元件值 (Value): 10kΩ, 100uF, STM32F103...
- 封装信息 (Footprint)

**2. 引脚连接 (Pins)**
- 每个元件的引脚定义
- 电源引脚 (VCC, GND)
- 信号引脚 (输入/输出)
- 特殊功能引脚

**3. 网络连接 (Nets)**
- 导线连接关系
- 网络名称 (Net Labels)
- 电源网络 (VCC, 3V3, GND)
- 信号网络

**4. 电源符号**
- VCC (正电源)
- GND (地)
- 3V3 (3.3V电源)
- 5V (5V电源)

#### 6.3.3 原理图元件库说明

系统内置以下常用元件库：

| 库名称 | 包含元件 |
|--------|---------|
| Device | 电阻、电容、电感、二极管、晶体管 |

| MCU | STM32、ATmega、ATtiny、ESP32 |

| Wireless | 蓝牙模块、WiFi模块 |
| Sensor | 温度传感器、光传感器、加速度计 |

1. **元件间距**：元件之间保持至少 100mil (2.54mm) 间距

   - 电源线用粗线 (Wire width: 1.5-2.0mm)
   - 信号线用中号线 (Wire width: 0.8-1.0mm)
   - 避免 90° 角，使用 45° 斜线网络命名**：
   -
3. ** 电源网络: VCC, GND, 3V3, 5V
   - 信号网络: 功能名称 (如 UART_TX, SPI_MOSI)
4. **元件编号**：
   - 电阻: R1, R2, R3...
   - 电容: C1, C2, C3...
   - 芯片: U1, U2, U3...
   - IC: IC1, IC2...

**2. 元件放置原则**

| 原则 | 说明 |
|------|------|
| 电源靠边 | 电源输入接口放在 PCB 边缘 |

- **电源线宽度**：根据电流计算，通常 1A 对应 0.5mm 线宽
- **信号线宽度**：通常 0.2-0.3mm
- **走线间距**：满足 2W 规则（W 为线宽）
- **过孔使用**：电源和地信号使用过孔连接多层

### 6.8 AI 工作原理（技术细节）

#### 6.8.1 AI 模型

本系统使用 **智谱 GLM-4** 大语言模型作为 AI 引擎：

- **模型**: glm-4
- **API**: https://open.bigmodel.cn/api/paas/v4
- **调用方式**: REST API
- **超时时间**: 120 秒

#### 6.8.2 系统提示词

AI 通过系统提示词理解 PCB 设计任务：

```
你是一个专业的电子电路设计助手，能够根据用户的需求描述，
分析并生成完整的电路项目方案。

你的任务是：
1. 理解用户的需求描述
2. 分析需要哪些电子元器件
3. 确定电路的技术参数
4. 生成合理的原理图布局和连线
5. 输出结构化的项目方案
```

#### 6.8.3 JSON 输出解析

AI 返回的方案需要解析为结构化数据：

```json
{
  "name": "5V稳压电源",
  "description": "输入12V直流电，输出5V直流电",
  "components": [
    {
      "name": "稳压芯片",
      "model": "LM7805",
      "package": "TO-220",
      "quantity": 1
    },
    {
      "name": "输入电容",
      "model": "10uF 25V",
      "package": "0805",
      "quantity": 1
    }
  ],
  "parameters": [
    {"key": "输入电压", "value": "12", "unit": "V DC"},
    {"key": "输出电压", "value": "5", "unit": "V DC"}
  ]
}
```

## 7. 导出功能

### 7.1 导出 Gerber 文件

Gerber 文件是 PCB 制造的标准格式。

**操作步骤**：

1. 在 PCB 编辑器中，点击 **"导出"** 菜单
2. 选择 **"Gerber"** 选项
3. 在弹出的设置对话框中配置：
   - 选择要导出的层
   - 设置输出目录
   - 设置文件前缀
4. 点击 **"导出"** 按钮
5. 等待导出完成
6. 下载生成的 Gerber 文件

**测试案例 7.1.1：导出 Gerber**

| 步骤 | 操作 | 预期结果 |
|------|------|----------|
| 1 | 点击导出菜单 | 显示导出选项 |
| 2 | 选择 Gerber | 打开导出设置 |
| 3 | 勾选 F.Cu, B.Cu, F.Silkscreen | 选中层高亮 |
| 4 | 点击导出 | 显示进度条 |
| 5 | 导出完成 | 显示成功消息和下载链接 |

### 7.2 导出 BOM (物料清单)

BOM 列出项目使用的所有元件信息。

**操作步骤**：

1. 点击 **"导出"** 菜单
2. 选择 **"BOM"** 选项
3. 配置格式（CSV/Excel）
4. 点击 **"导出"**

**测试案例 7.2.1：导出 BOM**

### 7.3 导出坐标文件

坐标文件用于贴片机自动放置元件。

**操作步骤**：

1. 点击 **"导出"** 菜单
2. 选择 **"坐标文件"** (Pick and Place)

## 9. 常见问题

### 9.1 启动问题

#### Q1: 后端启动失败，提示 "Module not found"

**解决方案**：

```bash
# 确保在正确的虚拟环境中运行
cd kicad-ai-auto/agent
./venv/Scripts/python.exe main.py
```

#### Q2: 前端提示 "Failed to connect to API"

**解决方案**：

1. 确认后端服务正在运行（端口 8000）
2. 确认前端配置了正确的代理（检查 vite.config.ts）
3. 刷新页面重试

### 9.2 功能问题

#### Q3: AI 助手无法使用

**解决方案**：

1. 检查是否配置了智谱 AI API Key（ZHIPU_API_KEY 环境变量）
2. 查看后端日志确认 API 调用是否成功
3. 智谱AI API免费额度用完需要充值

#### Q4: 无法导出 Gerber 文件

**解决方案**：

1. 确认 PCB 上有元件和走线
2. 检查是否设置了板边（Edge.Cuts 层）
3. 查看导出日志排查具体错误

### 9.3 性能问题

#### Q5: 画布操作卡顿

**解决方案**：

1. 增大栅格大小，减少渲染负担
2. 隐藏不需要的层
3. 使用选择工具代替框选
