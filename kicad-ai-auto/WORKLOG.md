### 问题排查过程

#### 问题1: AI返回12V电源模板而非ESP32

**现象**: 用户输入"设计一个ESP32的产品"，AI返回的是12V稳压电源模板

**根本原因**:
在 `ai_routes.py` 第1376行，条件判断有误：
```python
# 之前
if (answers and req.strip()) or has_specific_params:
```
当用户没有回答任何问题时，`answers` 是空字典 `{}`，在Python中空字典是falsy的，导致不会触发动态生成，而是使用模板匹配。

**修复**:
```python
# 修复后
if (answers is not None and req.strip()) or has_specific_params:
```
