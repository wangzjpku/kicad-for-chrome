## 项目概述

**KiCad AI Automation** 是一个 AI 驱动的 PCB 设计自动化系统。用户可以用自然语言描述电路需求，AI 自动生成原理图和 PCB 布局。

### 核心功能
- 🤖 **AI 智能设计**: 自然语言输入，自动识别电路类型
- 📐 **原理图生成**: AI 自动创建符合 KiCad 标准的原理图
- � PCB **PCB 布局**: 从原理图自动转换并优化 PCB
- 📤 **多格式导出**: Gerber, BOM, PDF, STEP 等

### 版本信息
- **当前版本**: v0.9.12
- **技术栈**:
  - 后端: Python 3.11+ / FastAPI
  - 前端: React 18+ / TypeScript / Vite
  - 渲染: Konva.js (Canvas)
  - KiCad: 9.0+ (IPC API)

## 快速开始

### Windows 本地运行

```bash
# 1. 启动后端 (端口 8000)
cd kicad-ai-auto/agent
venv\Scripts\python.exe main.py

# 2. 启动前端 (端口 3000)
cd kicad-ai-auto/web
npm run dev

# 3. 打开浏览器
# 访问 http://localhost:3000
```

### 快速重启 (代码修改后)

```bash
# 杀掉所有 Python 进程
taskkill //F //IM python.exe

# 重新启动后端
cd kicad-ai-auto/agent
venv\Scripts\python.exe main.py
```

## 功能使用指南

### 1. AI 智能创建项目

1. 点击主页 "🤖 AI 创建" 按钮
2. 输入电路需求，例如：
   - "设计一个LED闪烁电路，使用5V电源供电，通过555定时器芯片实现1Hz的闪烁频率"
   - "做一个USB转串口模块，使用CH340C芯片"
3. AI 自动分析并提出澄清问题
4. 回答问题后，AI 生成原理图方案
5. 确认原理图，设置 PCB 参数
6. 生成完整项目

### 2. 原理图编辑器

功能:
- 移动元件
- 添加/删除导线
- 添加网络标签
- 编辑元件属性
- 缩放/平移视图

### 3. PCB 编辑器

功能:
- 调整元件位置
- 手动/自动布线
- 添加过孔
- 铺铜
- 设计规则检查 (DRC)

### 4. 导出功能

支持的格式:
- Gerber (RS-274X)
- Drill (Excellon)
- BOM (CSV)
- Pick & Place (CSV)
- PDF
- SVG
- STEP (3D)

## 核心模块说明

### 后端 (agent/)

#### 1. main.py - 入口文件
```python
# 启动命令
uvicorn main:app --host 0.0.0.0 --port 8000 --reload

# 注册路由
app.include_router(ai_router, prefix="/api/v1/ai")
app.include_router(project_router, prefix="/api/v1/projects")
app.include_router(kicad_ipc_router, prefix="/api/kicad-ipc")
```

#### 2. routes/ai_routes.py - AI 核心模块
- **功能**: 电路分析、方案生成、原理图/PCB 生成
- **关键接口**:
  - `/api/v1/ai/clarify` - 获取澄清问题
  - `/api/v1/ai/analyze` - 分析需求，生成方案
- **AI 集成**: Kimi / GLM-4 大模型
- **模板系统**: 内置 NE555、ESP32、CH340 等模板

#### 3. routes/project_routes.py - 项目管理
- **功能**: 项目 CRUD、原理图/PCB 数据管理
- **关键接口**:
  - `GET /api/v1/projects` - 列表
  - `POST /api/v1/projects` - 创建
  - `GET /api/v1/projects/{id}/schematic` - 原理图
  - `GET /api/v1/projects/{id}/pcb/design` - PCB
- **数据持久化**: JSON 文件 (projects_data.json, pcb_data.json, schematic_data.json)

#### 4. routes/kicad_ipc_routes.py - KiCad 控制
- **功能**: KiCad 9.0+ IPC API 控制
- **关键接口**:
  - `/api/kicad-ipc/start` - 启动 KiCad
  - `/api/kicad-ipc/stop` - 停止
  - `/api/kicad-ipc/footprint` - 创建封装
  - `/api/kicad-ipc/items` - 获取元素列表

#### 5. 原理图/PCB 生成器
- `schematic_generator.py` - 原理图生成逻辑
- `pcb_generator.py` - PCB 生成逻辑
- `component_knowledge/` - 元件知识库

### 前端 (web/src/)

#### 1. App.tsx - 主应用
- 路由管理
- 状态初始化
- 布局组件

#### 2. pages/ProjectList.tsx - 项目列表页
- 展示所有项目
- AI 创建对话框入口

#### 3. components/AIProjectDialog.tsx - AI 创建对话框
- 8 步创建流程:
  1. 输入需求
  2. 明确细节
  3. 原理图确认
  4. PCB 参数
  5. PCB 确认
  6. 编辑确认
  7. 生成项目
  8. 最终确认

#### 4. editors/SchematicEditor.tsx - 原理图编辑器
- Konva.js Canvas 渲染
- 元件、导线、网络渲染
- 交互: 移动、缩放、平移

#### 5. editors/PCBEditor.tsx - PCB 编辑器
- 封装渲染 (Footprint)
- 走线 (Track)
- 过孔 (Via)
- 铺铜 (Zone)

#### 6. stores/kicadStore.ts - 状态管理
```typescript
interface KicadStore {
  // 项目状态
  currentProject: Project | null;
  projects: Project[];

  // 原理图状态
  schematicData: SchematicData | null;

  // PCB 状态
  pcbData: PCBData | null;

  // 编辑器状态
  selectedTool: string;
  zoom: number;
  pan: { x: number; y: number };
}
```

## 常见问题

### Q: AI 返回的是模板而不是我需要的电路
**A**: 请确保输入中包含具体的关键词（如"ESP32"、"STM32"、"NE555"），AI 会根据关键词触发动态生成。

### Q: 创建的项目原理图为空
**A**: 已修复 (v0.9.12)。请确保重启后端后重新测试。

### Q: Windows 下无法启动
**A**:
1. 确保已安装 KiCad 9.0+
2. 检查 .env 文件中的 KICAD_CLI_PATH
3. 运行诊断工具: `诊断工具.bat`

### Q: 后端代码修改不生效
**A**: 需要重启后端
```bash
taskkill //F //IM python.exe
cd agent && venv\Scripts\python.exe main.py
```

### Q: PCB 渲染显示空白
**A**: 检查浏览器控制台是否有错误，确认 PCB 数据已正确生成。
