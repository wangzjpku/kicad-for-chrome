### 4. 优化包体积

**问题**: 单一 bundle 体积 1,556 KB 过大

**解决方案**: 在 vite.config.ts 中配置 manualChunks 代码分割

**修改文件**: `kicad-ai-auto/web/vite.config.ts`

```typescript
build: {
  rollupOptions: {
    output: {
      manualChunks: {
        'vendor-react': ['react', 'react-dom', 'react-router-dom'],
        'vendor-konva': ['konva', 'react-konva'],
        'vendor-ui': ['@radix-ui/...'],
        'vendor-three': ['three', '@react-three/fiber', '@react-three/drei'],
      },
    },
  },
},
```

**优化结果**:
| 文件 | 优化前 | 优化后 |
|------|--------|--------|
| index.js | 1,556 KB | 250 KB |
| vendor-konva.js | - | 300 KB |
| vendor-three.js | - | 1,001 KB |
