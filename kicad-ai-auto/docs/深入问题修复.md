### 3. [中] TrackRenderer 性能优化 ✅

**文件**: `web/src/canvas/TrackRenderer.tsx`

**修复**:
- 使用 `useMemo` 缓存像素坐标计算结果
- 使用 `useMemo` 缓存颜色计算
- 提取内联函数到 useCallback 回调
- 避免每次渲染都重新创建函数

```typescript
// 修复前
const pixelPoints = points.flatMap((p) => [p.x * MM_TO_PX, p.y * MM_TO_PX]);

// 修复后
const pixelPoints = useMemo(() =>
  points.flatMap((p) => [p.x * MM_TO_PX, p.y * MM_TO_PX]),
  [points]
);
```
