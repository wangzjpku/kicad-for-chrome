## 已修复的问题

### ✅ 问题1: PCB尺寸参数未正确使用用户输入值 [已修复]

**问题描述**:
- 用户在需求中明确指定PCB尺寸为25x20mm
- AI在PCB参数设置步骤显示的尺寸为100x80mm（默认值）

**修复方案**:
- 修改文件: `web/src/components/AIProjectDialog.tsx`
- 在AI返回spec后，从parameters中提取`PCB尺寸`参数
- 解析尺寸格式如"50x40"，并设置到pcbParams状态

**修复代码**:
```typescript
// 从AI返回的参数中提取PCB尺寸
if (data.spec?.parameters) {
  const pcbSizeParam = data.spec.parameters.find(
    (p: ParameterSpec) => p.key === 'PCB尺寸' || p.key === 'pcb_size'
  );
  if (pcbSizeParam?.value) {
    const sizeMatch = pcbSizeParam.value.match(/(\d+)\s*[xX*×]\s*(\d+)/);
    if (sizeMatch) {
      const width = parseInt(sizeMatch[1], 10);
      const height = parseInt(sizeMatch[2], 10);
      if (width > 0 && height > 0) {
        setPcbParams(prev => ({ ...prev, width, height }));
      }
    }
  }
}
```

**状态**: ✅ 已修复 (v0.9.18)
