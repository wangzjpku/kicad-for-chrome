## Bug 清单

### BUG-003: 批量放置 API 不支持空格/Tab 分隔的 BOM 格式 [P1 - FIXED]
- **测试用例**: TC-009, TC-FLOW-005
- **根因**: `parse_bom_text()` 只用逗号 `split(",")` 解析，不支持空格分隔格式
- **修复文件**: `agent/schematic/bulk_placement.py`
- **修复内容**: 添加逗号/Tab/空格三种分隔符自动检测
- **验证**: CSV 和空格格式都正确返回组件

### BUG-007: PCB 编辑器控制台 404 错误 `/kicad-ipc/full-pcb` [P1 - FIXED]
- **测试用例**: TC-FLOW-002
- **根因**: 前端 `kicadIpcApi.getFullPCB()` 通过 `apiClient`(baseURL: `/api/v1`) 调用 `/kicad-ipc/full-pcb`，实际请求路径为 `/api/v1/kicad-ipc/full-pcb`，但后端注册在 `/api/kicad-ipc/full-pcb`
- **修复文件**: `web/src/services/api.ts`
- **修复内容**: `getFullPCB` 使用 `axios.get('/api/kicad-ipc/full-pcb')` 直接指定正确路径
- **验证**: 编辑器打开后 0 个控制台错误

### BUG-002: `getPCBItems` 调用不存在的 `/pcb/items` 端点 [P1 - FIXED]
- **测试用例**: TC-API-008
- **根因**: 前端 `pcbApi.getPCBItems()` 调用 `/projects/:id/pcb/items`，后端无此路由
- **修复文件**: `web/src/services/api.ts`
- **修复内容**: 改为使用 `/projects/:id/pcb/design` 端点
- **验证**: API 调用不再返回 404

### BUG-006: AI 分析不含模板关键词时返回 0 组件 [P3 - 非代码问题]
- **根因**: DeepSeek API 未配置有效 API Key 或返回空结果
- **说明**: 含模板关键词(ESP32, STM32等)时走 mock 路径正常工作。这是 AI API 配置问题，非代码 bug

### BUG-008: React Konva defaultProps 弃用警告 [P3 - 第三方库问题]
- **根因**: Konva.js 使用了已弃用的 React defaultProps
- **说明**: 不影响功能，等待 Konva.js 更新即可
